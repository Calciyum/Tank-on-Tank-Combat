# Tank-on-Tank-Combat
Builds of Tank on Tank Combat throughout its development

This doesn't contain the first two builds as they are technically lost to time but the first build had just the display of the map as well as the tank displaying.
Build 2 added turn changing, movement, and background color changing.

Small bit of technical work needed to install, when installing this game place it on your desktop and on your C drive to avoid more editing,
then go into the text files containing the code and near the top, on ALL the image loaders, replace the text to the right of "Users\" with your user id on your computer.

Also you may need to install python, pygame, and run this in visual studio code, instructions for those are online
